Case piloto — ClimateWise

ClimateWise (FIMCE — Framework Integrado de Modelagem Climático-Econômica) é o piloto GEO da Khabs: transformar uma marca técnica forte no GitHub em fonte citeável para ChatGPT, Perplexity, Gemini e AI Overviews.

Marca: ClimateWise Repo: ClimateAI Licença: MIT Idioma: pt-BR

Desafio

Marca técnica forte no GitHub, baixa citabilidade em motores generativos

O ClimateWise já tinha repositório público, stack documentada (FastAPI + React, NOAA / Embrapa / OpenMeteo) e posicionamento claro em atuária climática e seguros paramétricos. O gap: engines generativas raramente citam o produto porque o conteúdo não estava estruturado para resposta — sem blocos answer-first, FAQ com schema, tabela comparativa, claims com evidência, nem llms.txt / pacote docs/geo no próprio repo.

  • ▸ Autoridade técnica concentrada em README e código, pouco “chunkável” para LLMs
  • ▸ Entidade ClimateWise / FIMCE pouco explícita para Knowledge Graph e sameAs
  • ▸ Sem baseline formal de menções em ChatGPT, Perplexity, Gemini e AI Overviews

Entrega

O que entregamos

Pacote GEO citeável A–D, manifesto llms.txt e pasta docs/geo publicados no repositório ClimateAI.

A

Answer-first

Bloco hub “O que é o ClimateWise?”, para quem é, o que faz e snippet pronto para citação por LLMs — com stack verificável no repo.

B

FAQ + schema

Perguntas citeáveis (FIMCE, fontes climáticas, SUSEP, Partner API, ClimateWise vs ClimateAI) + JSON-LD FAQPage / SoftwareApplication.

C

Tabela comparativa

Comparativo estruturado ClimateWise vs API meteorológica “pura” vs planilha atuarial — para prompts de comparação e “melhor ferramenta”.

D

Claims com evidência

Afirmações ancoradas em artefatos do repositório (README, Partner API, integrações NOAA/Embrapa/OpenMeteo) — sem claims inventados.

llms.txt

Manifesto machine-readable

Arquivo na raiz do ClimateAI descrevendo marca, produto, páginas GEO e Partner API — ponto de entrada para crawlers e agentes.

docs/geo

Pacote publicado no repo

README do pacote, pacote-AD-climatewise.md completo e schema FAQ em docs/geo/ no GitHub.
